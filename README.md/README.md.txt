# 📊 Mutual Fund Analytics

A comprehensive Data Analytics and Business Intelligence project developed to analyze mutual fund performance, investor behaviour, and industry trends using Python, SQL, SQLite, and Power BI.

---

## 📌 Project Overview

This project focuses on analyzing mutual fund datasets through an end-to-end analytics pipeline. The project includes data preprocessing, exploratory data analysis (EDA), financial performance analytics, advanced analytics, and interactive Power BI dashboards.

---

## 🎯 Objectives

- Analyze mutual fund industry data.
- Evaluate mutual fund performance using financial metrics.
- Study investor behaviour and transaction patterns.
- Develop interactive dashboards for business insights.
- Apply advanced analytics for investment decision support.
